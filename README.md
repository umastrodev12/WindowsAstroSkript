## Iniciando o Setup

### Scripts fáceis feitos PARA BAIXAR MEUS APPS E LINGUAGENS FAVORITOS!!!!

### Script que instala os apps!

```bash
cd scripts
sh appinstal.sh # Script que instala os Apps
```

### Script que instala as linguagens!!

```bash
sh langsinstall.sh
```

### E Por fim, script que instala os games!

```bash
sh gamesinstall.sh
```

## Após reiniciar, os apps e linguagens estão prontinhos!
